# Checklist App 📝

A simple and interactive checklist web application built using HTML, CSS, and JavaScript.  
This project allows users to create, manage, and track tasks in a clean and minimal UI.

---

## 🚀 Features

- ➕ Add new checklist items
- ✅ Mark tasks as completed
- ❌ Delete individual items
- 🧹 Clear or manage completed tasks
- 💾 Persistent UI state (if localStorage is implemented)
- 📱 Responsive design for mobile and desktop

---

## 🛠️ Built With

- HTML5 – Structure
- CSS3 – Styling and layout
- JavaScript (Vanilla JS) – Logic and interactivity
